# brand-ui-system

The skill. `SKILL.md` is the contract your agent reads; everything else is material it loads on demand.

Install, usage examples and maintenance live in the repository root: [`../README.md`](../README.md).

```text
SKILL.md                 the contract
references/              what the routing table loads
assets/bootstrap/        runnable starter
assets/brand-lint.mjs    gate for the exclusion table
assets/install.*         install for one or many agents
```
